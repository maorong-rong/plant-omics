# 未接入源清单（可接入但当前没有工具）

> 用途：回答"哪些库现在能接、为什么还没接"。
> 事实来源：`docs/源登记表.md`（唯一真相）与 `记录/` 各调研记录；本文件不新增实测结论，只做汇总与理由归类。
> 更新口径：任何一项状态变化，先改源登记表，再回来改本文件。

## 一、Strawberry Data Hub：同一站点内 15 个模块未接

已接 5 个意图工具：`catalog`、`gene_lookup`、`expression`、`synteny`、`tf_members`。

| 模块 | 为什么没接 | 接入前提 |
|---|---|---|
| `families` 精选基因家族 | 未实测端点；家族页语义未确认 | 实测列表与详情端点、确认家族 ID 空间 |
| `gwas` 关联分析 | 响应形态未测；"可出图"意味着返回可能是图片二进制 | 只取结构化字段，图片不接 |
| `metabolomics` 代谢组 | 特征/矩阵/统计三类混合，矩阵体积未知 | 实测矩阵大小，定聚合规则 |
| `single-cell` 单细胞 | markers / embedding / GO 多种响应，embedding 可能很大 | 实测各端点字节数，只接 markers 与 GO |
| `pangenome` 泛基因组 | 正交群/图谱结构复杂，未经实测 | 先跑通一个正交群查询 |
| `epigenomics` 表观组 | 项目/区域/状态模型三段，未测 | 先测 catalog 已有、业务端点未测 |
| `coexpression` 共表达网络 | 图结构，体积与裁剪方式未定 | 实测后定裁剪 |
| `mirna` miRNA 位点 | 未测 | 实测 |
| `downloads` 文件下载 | 316 文件 / 35.4 GB，本质是取文件 | **与"不做数据镜像"边界冲突，倾向永久不接**，最多给路径 |
| `sequences` 批量导出（POST） | POST 副作用未证明；结果可能是大 FASTA | 需先解决"只给统计还是给序列"的取舍 |
| `publications` 文献元数据 | 302 条，未测 | 实测后做意图级工具 |

**共同理由**：工具是给模型选的界面，77 个路径不能一对一暴露；当前 21/40 常驻工具，仍有余量，但每加一个应满足"独立查询意图 + 已实测 + 能以 4 KB 裁剪表达"。

## 二、已定级或已验明接口、但没写工具的源

| 源 | 等级 | 已验到什么 | 为什么不接 |
|---|---|---|---|
| **NGDC 门户 API** | T1（目录级） | `/api/resource/list/zh` 200 / 89,744 B，按 10 大类返回全部 NGDC 库 | 只到"数据库目录"层，**查不了数据**；适合做源发现工具，需先有检索层才有消费方 |
| ~~Gramene v69~~ | **已接入**（0.7.0，4 个工具） | 见[源登记表](源登记表.md) §一 |
| **Ensembl Plants** | T1 候选 | 只验过 `division/EnsemblPlants` 200 / 196 KB | 逐物种查询端点未测；物种目录本身只够做源发现 |
| **EBI Expression Atlas** | T1 候选 | `gxa/json/experiments` 200 / **2.6 MB** | 单次响应极大，必须先设计聚合才能接；文档页未核 |
| **STRING** | T1 候选 | `api/json/version` 200 / 84 B | 只验了 version 端点，互作查询未测 |
| **UniProt** | T1 候选 | `uniprotkb/search` 200 / 17 KB | 文档页未核，字段裁剪未设计 |

## 三、疑似 T2（老派参数化 URL），需实测后才能进 `src/sources/`

| 源 | 现状 | 卡点 |
|---|---|---|
| **PlantTFDB** | 两次连接超时（20 s、15 s，curl 000），此前曾 200 | 超时不等于 T3；换网络/时段复测，稳定则按 T2 接 |
| **PlantPan** | `POST /plantpan/index_search_select` 200，`term` 返回 `[{ID,Name}]`；无 term 返回全量 10 物种 | 只有"物种搜索"一个意图；10 物种含草莓但无小麦 |
| **PPGR** | `GET /ppgr/expression/project/list` 200 / **360,588 B** 全量数组；`draw/start/length` 被忽略 | 只能做"表达项目目录"，服务端分页不可用，必须全量聚合；不能按基因查表达 |
| **RED**（水稻表达） | 8 个端点在懒加载 chunk；`expression` 查询恒为空，`fpkm` 四个 ID 全 404 空 body | **没有拿到任何正例**，结案；除非出现有效 ID 样例 |
| **BRAD**（十字花科） | 已验 2 个意图：物种目录 200 / 12,880 B、基因 ID→位置 200 / 117 B | 缺基因时返回 **500 + Django 调试页**（泄露内部路径），查无与错误 ID 不可区分；宿主是明文 HTTP + IP。**错误语义不解决不接** |
| **GenBase** | `api/file/fasta` 200 / 30,615 B、`gbf` 200 / 66,740 B；查无是 200 + 0 字节 | 只有 accession→序列文本；`query/nuc` 404、`search/all/acclst` 返回 0 字节，**无可编程检索**；植物覆盖未确认 |

## 六、结论

| ~~Gramene v69~~ | **已接入**（0.7.0，4 个工具） | 见[源登记表](源登记表.md) §一 |

**其次值得做的是 Strawberry 的高频模块**（`gwas`、`pangenome`、`single-cell`、`epigenomics`），同一底座、鉴权与错误语义已解决，增量成本最低。

**不建议做的**：`downloads`（数据镜像边界）、BRAD（错误语义不安全）、RED（无正例）、CNGBdb 与 GSA（路径未知，猜就是赌）。
