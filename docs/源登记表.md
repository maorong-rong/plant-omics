**WheatOmics 要点**（写清楚，免得下次重新查）：

- 信封统一 `{success, message, timestamp, data}`；`success=false` 时 `data` 不可用。
- **版本口径：本仓不判定，只转述上游。** 上游 `genome` 字段返回 `Chinese_Spring1.0`；
  JBrowse 轨道写 `IWGSCv1.1_HC_LC`；基因 ID 有 `01G/02G/03G` 三种前缀，而各端点对
  "v1/v2/v3"的叫法并不一致。**组装版本、注释版本、站点内部映射表是三件事，不能按 ID 外观互相推断。**
  > ⚠️ 2026-10-28 更正：本表此前一处写"表达量基于 IWGSC v2.1（02G）"、另一处写"统一转 IWGSC v1.1（02G）"，
  > 属**转述不一致**（审查 R06）。现在统一改成本段口径，并在 `manifest.versionNote` 里原样透出到每条工具输出。
- 表达值单位随项目而定且上游未逐点标注，**跨项目不可直接比较大小**。
- 平台**自带 MCP server**（`GET /api/mcp/sse`）—— 本仓不是它的替代品，价值在于把它和别的国内库并成同一套工具。
- `GET /api/expression/projects` 单次返回约 **600 KB**，任何场景都不许整表透传给模型。
