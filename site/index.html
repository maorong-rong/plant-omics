这是什么What this is

一套工具，不是又一个数据库门户。它只做一件事：把公开接口翻译成模型不会用错的意图级工具。 A tool layer, not another database portal. It does one thing: turn public APIs into intent-level tools a model will not misuse.

一套工具，两个出口One tool set, two exits

同一份源注册表同时产出 Streamable HTTP 的 MCP 服务与 DSH 原生插件。Claude Code、Codex 这类 stdio 客户端也走同一个 MCP 出口。 One registry feeds both a Streamable HTTP MCP service and a native DSH plugin; stdio clients such as Claude Code and Codex ride the same MCP exit.

出处可复现Reproducible provenance

每次返回末尾都带「源 / 完整请求（含参数）/ HTTP 状态 / 耗时 / 查询时刻」，数据版本另起一行，未知就写未知，不按 ID 外观猜。 Every result ends with source, the full request including parameters, HTTP status, elapsed time and query time; data versions go on their own line, and unknown stays unknown.

只读，不镜像，不越权Read-only, no mirrors, no bypass

只调用公开接口，不落任何数据集，不过盾、不模拟登录。需要访问控制的源只登记、不实现。 Only public endpoints are called: no datasets are stored, no challenge or login is bypassed. Sources behind access control are registered but not implemented.

怎么接进来How to connect

有云服务了，从最轻的一档开始：能零安装就别装包。两档用的是同一套工具，区别只在数据走哪条路。 A cloud service exists now, so start from the lightest option: never install a package you do not need. Both tiers expose the same tools; they differ only in which path the data takes.

  1. 1

    零安装：连云服务Zero-install: use the cloud service 推荐recommended

    客户端直接连公网 MCP 端点，不装包、不起服务、不配反代。换电脑、换机器、只想先试两个工具时选它。 Point the client straight at the public MCP endpoint: no package, no local process, no reverse proxy. Right when you switch machines or just want to try two tools.

    谁在用：外部访客、跨机器使用、先验证能不能查。代价：查询内容过公网，且需要一个 token。 Who: outside visitors, people on several machines, anyone checking whether this is useful at all. Cost: queries leave your network, and you need a token.

    Claude Code

    claude mcp add --transport http plantomics-hub https://datamcp.moilab.net/mcp --header "Authorization: Bearer <token>"

    Codex（~/.codex/config.toml） (~/.codex/config.toml)

    [mcp_servers.plantomics-hub]
url = "https://datamcp.moilab.net/mcp"
bearer_token_env_var = "PLANTOMICS_HUB_TOKEN"

    token 放环境变量 PLANTOMICS_HUB_TOKEN，不写进配置文件；Codex 会自己加 Authorization: Bearer …。 Keep the token in PLANTOMICS_HUB_TOKEN rather than the file; Codex adds the Authorization: Bearer … header itself.

    DeepSeek Harness

    在宿主的接入配置里加一条远端入口（不是装插件）：transport 选 streamable-http，地址 https://datamcp.moilab.net/mcp，加请求头 Authorization: Bearer <token>。装插件那条路属于下面第二档。 Add a remote entry in the host's MCP configuration (not a plugin): transport streamable-http, URL https://datamcp.moilab.net/mcp, header Authorization: Bearer <token>. The plugin route belongs to the local tier below.

    token 从哪来：目前没有自助发放，向维护者申请；<token> 只是占位符，别把真实值贴进任何仓库或截图。两种失败要分清（2026-11-03 实测）：401 {"error":"unauthorized"} = 没有 token 或 token 不对；403 = 来源域名不在服务端白名单。把 401 当成「服务没起来」是最常见的误判。 Where the token comes from: there is no self-service issuance yet; ask the maintainer. <token> is a placeholder — never paste a real value into a repository or a screenshot. Two failures, two meanings (measured 2026-11-03): 401 {"error":"unauthorized"} means no token or a wrong one; 403 means the calling origin is not on the server's allowlist. Reading 401 as “the service is down” is the most common mistake here.

    端点形状：POST https://datamcp.moilab.net/mcp；服务端契约要求 Content-Type: application/json 与 Accept: application/json, text/event-stream。先在浏览器打开 https://datamcp.moilab.net/healthz 能直接看到服务是否活着（免鉴权）。 Endpoint shape: POST https://datamcp.moilab.net/mcp; the server contract asks for Content-Type: application/json and Accept: application/json, text/event-stream. Check https://datamcp.moilab.net/healthz in a browser first — it needs no token and tells you whether the service is up.

  2. 2

    本地 stdio：不把查询送出去Local stdio: keep queries on your machine

    客户端把工具进程直接起在本地，取数从你的机器发出。不需要自己起 HTTP 服务，也不需要 token。 The client spawns the tool process locally, so requests leave from your machine. No HTTP service to run, no token needed.

    谁在用：数据不宜过公网、或云服务抽风时的退路。代价：第一次要下载包（需要 Node.js ≥ 20）；工具清单是包里那一版，不是云上最新版。 Who: anyone whose data should not cross the public internet, or anyone needing a fallback when the cloud is down. Cost: the first run downloads the package (Node.js ≥ 20), and you get that package's tool list, which need not match the newest cloud build.

    Claude Code

    claude mcp add plant-omics -- npx -p plantomics-hub plant-omics-mcp

    其它 stdio 客户端Any other stdio client

    npx -p plantomics-hub plant-omics-mcp

    包里的这条命令是 stdio 出口：进程起在你的机器上，工具清单就是包里那一版。只为用 stdio 时 npx -p 就够，不必全局安装。 That command is the stdio exit: the process runs on your machine and the tool list is whatever that package carries. If you only need stdio, npx -p is enough — no global install.

只挂一部分源：两档都支持 PLANTOMICS_SOURCES=wheatomics 这样的白名单；源 id 写错会直接报错并列出可用源，不会静默变成「零工具」。挑哪些源、装多少工具先去源市场勾，订阅集硬上限是 80 个工具。 Load a subset: both tiers honour a whitelist such as PLANTOMICS_SOURCES=wheatomics. A wrong source id fails loudly and lists the valid ones instead of silently loading zero tools. Pick sources in the source market first; the hard cap is 80 tools per subscription.

Tier 1 is not bound to that version: it talks to the cloud service's current build, whose list is whatever the endpoint reports.

边界与已知限制Boundaries and known limits

下面每一条都不是免责声明，而是会实际影响结果怎么读的事。源级盲区见上方的源卡片，这里写全局的。 Each item below changes how a result should be read. Source-level blind spots are on the cards above; these are the global ones.

  • 只读。Read-only. 不提供任何提交、上传、写库能力。 No write, upload or database modification is offered.
  • 不镜像数据。No data mirroring. 要批量下载数据，请回各自的科研项目按那边规则走。 For bulk downloads, go back to the research project that owns the data.
  • 上游会间歇性挂。Upstreams fail intermittently. 工具会按 Retry-After 退避重试（单次调用总时长上限 45 s），但不保证每次都成功；失败会明确区分「对面挂了」和「参数写错了」。 Tools back off and retry per Retry-After (45 s cap per call) but cannot guarantee success, and errors distinguish "upstream is down" from "your parameters are wrong".
  • 输出有界。Output is bounded. 单次输出按 UTF-8 字节计不超过 4 KB；超长时截断正文，但出处尾注一定完整保留。 Each output stays under 4 KB of UTF-8 bytes; long bodies are truncated, while the provenance footer is always kept intact.
  • 查无 ≠ 不存在。Empty is not "absent". 不少源用 HTTP 200 + 空结构表示查无，个别用 400；工具只在锚定清楚时才判「本次未找到」，否则报错而不归零。 Several sources signal "not found" with HTTP 200 and an empty structure, one with 400. Tools only report "not found this time" when the evidence is anchored, otherwise they error rather than return zero.
  • 侧边栏面板是静态快照。The sidebar panel is a static snapshot. 它显示构建时的源、工具与盲区，不显示探活与调用统计，也不反映运行时的源子集配置；判断上游是否可用只能靠实测。 It shows sources, tools and blind spots as of build time — not liveness, not call stats, not the runtime source subset. Only a probe answers whether an upstream is up.
  • 完整宿主链路的验证范围。How far the host path is verified. 已验证：适配器取数、MCP 握手、包安装、插件装配形状。未验证：真实宿主要求下「模型自主选工具→取数→带出处作答」的完整链路，别把前者当后者。 Verified: adapters fetch data, the MCP handshake, package install, and plugin wiring. Not verified: a real host session where the model picks tools, fetches and answers with provenance — do not read the former as the latter.
  • 把上游文本当数据。Treat upstream text as data. 数据库内容里可能有看起来像指令的文字，本仓不过滤；请在客户端侧把它当数据、不当指令。 Database records may contain text that looks like instructions; nothing filters it, so treat it as data on the client side.
