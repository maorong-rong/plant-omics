# `web/` —— 独立 Web 应用（试调页）

状态：**已实现**（2026-10-31）。设计说明在 [DESIGN.md](DESIGN.md)，历史线框在 [sketch.html](sketch.html)（仅供参考，`index.html` 才是实现）。

## 1. 它做什么

浏览器打开就能：浏览源与工具（读构建期快照，离线可用）→ 看某个工具的参数表（由服务端 `inputSchema` 生成）→ **对真实服务发起一次 `tools/call`** → 看结果与出处尾注。

## 2. 怎么跑

**本地（推荐）：开发服务器复刻线上同源布局**

```bash
# 1) 起服务（另开一个窗口/进程），带 token
$env:PLANTOMICS_HUB_TOKEN='<你的 token>'
$env:PLANTOMICS_HUB_PORT='8793'
node dist/service/cli.js

# 2) 起 web 开发服务器：静态站 + /mcp、/healthz 反代到上面那个服务
$env:PLANTOMICS_UPSTREAM='http://127.0.0.1:8793'
node web/dev-server.mjs 8094
# 打开 http://127.0.0.1:8094/
```

为什么必须这么起：服务端**不下发 CORS 头**且**校验 Origin**，浏览器里「前端 A 端口 + 服务 B 端口」一定失败。
`dev-server.mjs` 只是把 Nginx 的布局（静态站 + `/mcp` 反代）在本地复刻一遍，上线时换成 Nginx 配置即可。

> **`PLANTOMICS_STRIP_SUBSET=1` 是开发服务器上的负控开关**（模拟「旧版服务端不认 `x-plantomics-sources`、把全集当子集返回」），
> **仅用于本地验证前端会不会把全集冒充成子集，生产部署绝不启用**；Nginx 配置里没有、也不该有这一项。

`file://` 直开也能看浏览页（快照），但**不能调用**——没有同源服务，页面会显示明确禁用态。

**数据**：`web/data/catalog.js` 与 `web/assets/source-icons.js`、`web/favicon.svg` 由 `node site/scripts/build-data.mjs` 生成/投递，勿手改。
顺序（草莓置顶 + 其余注册表原序）就在这份数据里，`web/` **不重新排序**。

## 3. 三条硬规矩

1. **token 不进代码**：只从右上输入框读，只放 `sessionStorage`；请求头里出现，界面/URL/日志只显示 `<token>` 占位。
   `sessionStorage` 的生命周期：同一标签页内刷新仍保留；关闭标签页**通常会**清除，但浏览器恢复会话时**可能保留**。
要立刻结束，请点右上「**清除 token**」——它确定会清掉存储并回到未认证的禁用态。
关闭标签页**不能**当作清除的保证（浏览器可能恢复会话），文档与界面只说可能性，确定性只挂在按钮上。
2. **服务不可用是明确禁用态**：调用按钮 `disabled` 且文案改成「发起调用（服务未就绪）」，结果区说明为什么（没 token / 连不上 / 拿不到清单），绝不渲染「看起来能调」的按钮。
3. **数字不混口径**：浏览页显示构建期快照数字并标 commit / 快照时间 / `build sourceRev`；服务端返回的 `/healthz` 与 `tools/list` 才是实时真相，两边不一致时页面用横幅**明说差在哪**（数量差、工具增减），以服务端为准。

### 措辞检查（机械，不靠复读）

```bash
node web/scripts/check-wording.mjs    # 未加限定词的清除断言、或缺少「通常/可能/按钮」的说法 → 非零退出
```

为什么要有它：token 生命周期那句话改了三轮都没改干净。**会误导安全判断的措辞不能靠人复读**，所以做成脚本。

设计上刻意**不枚举坏句子**——黑名单永远补不全，不在词表里的新写法就被当成没问题（前一轮的残留就是这么漏过去的，因为那句话不在词表里）。现在改成**正向约束**：
凡句子同时出现「关」这个动作与「标签页」这个对象，同句必须带限定词（通常 / 可能 / 不保证 / 不能当作…），否则失败。这样任何新措辞都逃不掉，不需要预判别人怎么写。
另外两条正向要求：README 与输入框提示里必须有「通常 / 恢复会话 / 清除 token」三件事；把选源说成访问隔离时必须带否定语境（写「不是…」放行，不写才报）。

**负控**（都真跑过，隔离副本里做）：把旧断言放回 → exit 1；把选源说成访问隔离且不加否定 → exit 1；写「不是访问隔离」→ exit 0（不误杀）；删掉 README 里的「恢复会话」→ exit 1 并点名缺哪句；其余情况基线 exit 0。

## 4. 页面

| 路由 | 内容 |
|---|---|
| `#/sources` | 源列表（8 个，带图标与等级）+ 过滤 + 源详情（工具清单、盲区原文） |
| `#/sources/<id>` | 同上，定位到某个源 |
| `#/tools/<name>` | 工具详情：描述、参数表（需要服务端 `inputSchema`）、去试调 |
| `#/try/<name>` | 试调：参数表单 + 请求预览（token 占位）+ 结果（状态 / 正文 / 出处高亮） |

默认试调工具是 `wheatomics_search_known_genes`（必填参数是 `searchid`，例如 `VRN1`）。

## 4.1 选源页（`picker.html`，静态版）

「源市场」形状的第一版：卡片网格勾选源，实时算出会装进上下文的工具数与 token。

- 每张卡：图标（`source-icons.js`）+ 名称 + 作物标签（来自 `manifest.species`，页面注明**不等于收录范围**）+ 工具数 + 等级。
- 摘要条：已选源 / 工具数（含 2 个 `hub_*` 元工具）/ **预估 token** / 上限 40，配预算进度条（接近上限转黄、超限转红）。
  token 估算的出处：论文侧用 cl100k_base 实测「全量 `tools/list`」合计 **10 253 token**，除以 37 个工具 **≈ 277**，取整按 **280/工具**（测量对象是工具声明本身：名字 + 描述 + `inputSchema`；换 tokenizer 或改描述就会变，所以只作估算）。
- 超过 40 直接弹红色横幅「**装不下**」，并写清后果是「工具声明要全量常驻上下文，超了得先有检索层或砍源」，不是「慢一点」。
- 作物筛选：小麦 / 水稻 / 玉米 / 草莓 / 甘蔗 / 拟南芥 / 橡胶蒲公英 / 病原真菌（按数据里实际出现的作物生成，不写死）。
- 「复制选择」输出 `PLANTOMICS_SOURCES=wheatomics,gwh,…`，直接用于启动服务时限定子集。
- **接到真实服务核对**：填服务地址（默认同源 `/mcp`）与 token，点「连接并核对」→ 发 `x-plantomics-sources: <勾选的源 id>`，然后**回读这一次的 `tools/list`**。
  - 返回的工具集合与勾选逐个对上 → 绿色「服务端按子集返回」；
  - 返回的是**全集**（例如 37 个）→ 红色「**服务端未按子集返回（返回了全集）**」，并说明最可能是旧版本不认这个头或代理把头剥了——**页面不会把这种情况当成「已按选择过滤」**；
  - 服务端返回 400（未知源 id 等）→ 原样显示 `detail`；
  - 401 / 403 / 连不上 → 分别给出该改什么。
  - 勾选与预算计算仍全在本地；只有点这个按钮才发一次请求。


## 5. 验证过的状态

| 场景 | 表现 |
|---|---|
| 服务正常 + 有 token | 状态灯绿、8 源 37 工具、表单可填、真实调用 200 并显示出处 |
| 服务正常 + 无 token | 调用按钮禁用、结果区提示先填 token、请求预览仍显示骨架 |
| 服务没起（502） | 状态灯红 + 红色横幅（三条排查项）+ 所有调用禁用 |
| token 错（401） | 横幅「token 被拒」+ 调用禁用；不回显 token 片段 |
| 域名不在白名单（403） | 横幅给出部署侧该改什么（`PLANTOMICS_HUB_ALLOWED_HOSTS`） |
| 快照与服务端数字/工具不一致 | 黄色横幅列出差多少、哪些工具，说明以服务端为准 |
